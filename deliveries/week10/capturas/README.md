# Capturas de la demostración

La app compilada igual que la publicada, con el frontend nuevo, contra el API con los datos `2026.10.8` y el contrato 1.7, el 25 de octubre de 2026. Las de celular son de 390 × 844 puntos y las de escritorio, de 1 440 × 900. Las fotos son de Wikimedia Commons, con su autor y su licencia a la vista.
